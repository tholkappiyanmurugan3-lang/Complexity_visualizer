# 📈 Complexity Visualizer

An interactive web application built using **Flask**, **HTML**, **CSS**, and **JavaScript** to visualize the growth of common time complexities.

## Features

- Interactive slider for input size n
- Visualizes:
  - O(1)
  - O(log n)
  - O(n)
  - O(n log n)
  - O(n²)
- Responsive and modern UI
- Built with Flask

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Installation

```bash
py -m pip install -r requirements.txt
```

Run the application:

```bash
py app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
